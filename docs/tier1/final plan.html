Agent authority: GPT-5.6 Sol chooses among allow-listed read-only inspection/orchestration tools and explains outputs. Deterministic code owns validation, schedules, quantities, costs, thresholds, confirmation requirements, and safety rules.

8. Performance Diagnosis And VPS Gate

Current evidence-based hypothesis, not a final cause: most delay is likely remote I/O and model inference. The natural-language path can perform one profile-extraction response plus a two-response tool loop; weather performs geocoding then forecast; database saves wrap the flow; the browser receives no intermediate result. High reasoning is currently the default.

Why RAM may not help: in-process RAG/ranking/scheduling are computationally small. More CPU/RAM will not shorten OpenAI or Open-Meteo network/model time.

Resize decision rule: consider infrastructure only when measurements show CPU >85%, sustained event-loop lag, memory pressure/swap, or database contention dominates the critical path. Then record current Droplet plan, proposed plan, credit-only monthly/hourly cost, restart/downtime, rollback, and exact target. Pause for Koushik's separate confirmation before changing the account or Droplet.
